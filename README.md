# MICO-FLEET-SAAS-ENTERPRISE
Una plataforma que rentas a brokers de carga (camiones) por suscripción mensual. Cada broker tiene su espacio privado, con su marca, y una IA que: - Busca cargas en DAT/Truckstop automáticamente - Negocia precios en inglés por él - Traduce todo al español - Confirma cargas y asigna camiones (95% automático) - Tú cobras cada mes solo con Stripe
